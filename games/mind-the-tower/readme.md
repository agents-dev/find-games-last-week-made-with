## Source description

The Defold README describes a memory and block-stacking game: memorize a star location, catch and stack falling blocks, climb, score or lose, and replay. The repository contains game.project, collection, player, block, star, controller and HUD scripts plus gameplay screenshots. The cited commit page shows a direct Claude Opus 4.8 trailer.
