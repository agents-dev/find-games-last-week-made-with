## Source description

The README explicitly identifies chess3dastra as a fully playable 3D and 2D chess game built end-to-end with GPT-6 Astra. It documents full chess rules, three computer difficulty levels, click and keyboard moves, notation input, undo, move history, captures, themes and localStorage save/restore. The source contains the Three.js 3D renderer, an accessible DOM/SVG 2D renderer, chess.js rules, a negamax/alpha-beta computer opponent in a Web Worker, Node tests and Playwright browser tests.
