## Source description

The repository README describes a browser tower-defense game with placing and upgrading OSRS-themed towers, winding roads, escalating waves, gold, bosses, prayers, traps, fusions, achievements, saves and a collection log. The repository contains the Canvas game engine, renderer, simulation, data, UI and extensive unit/Playwright test source. Its commit history contains many exact Claude Opus 5 trailers on gameplay commits, including boss mechanics, waves, towers, traps and UI. The configured GitHub Pages URL redirected during verification, so no live-play claim is made; count the runnable source game once.
