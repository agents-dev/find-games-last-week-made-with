## Source description

The public repository is a top-down pixel RPG with a Godot 4.7 project, live browser demo, world scenes, movement, quests, dialogue, field skills, inventory, progression, economy and tactical combat. It includes fallback assets, Steam-style gameplay screenshots and scripted QA. The cited commit contains direct Claude Fable 5.1 trailers. Count the game once and place it in Non-Browser Engines because the source is a native Godot project even though a web export is also published.
