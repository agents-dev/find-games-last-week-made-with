## Source description

The creator profile links this public repository as a playable Highland-games arcade lobby. The source contains a Rust deterministic movement and door-proximity simulation, a WebAssembly boundary, keyboard/pointer input, Canvas2D rendering, a game registry and launch navigation. The README provides a live deployment and two screenshots. The cited commit contains a direct Claude Fable 5 trailer. Count the playable arcade-lobby game as one browser unit; its mounted Wild Haggis Survivors and Just Five More Minutes projects remain separate repository records.
