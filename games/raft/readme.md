## Source description

The README explicitly says this is a single-file 3D game written entirely with Claude Opus 4.6. It documents a complete survival and building loop on an infinite ocean: walk on a raft, use a hook to collect supplies, row, expand the raft through a building panel, add multi-level floors, columns and stairs, and demolish structures. The repository contains index.html and a live deployed build at http://aiznb.com/raft/.
