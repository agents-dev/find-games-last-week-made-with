## Source description

The README identifies Last Metro as a playable GPT-6 browser game and documents a first-person escape loop: restore power, solve three puzzles, evade a listening shadow, and choose one of two train endings. The repository contains TypeScript and Three.js runtime code, Rapier physics, authored station geometry, enemy and stealth systems, audio, accessibility settings, saves, source assets, CI and Playwright end-to-end tests. It provides local Vite launch instructions but no public hosted deployment, so classify it under Browser Games without claiming live browser verification.
