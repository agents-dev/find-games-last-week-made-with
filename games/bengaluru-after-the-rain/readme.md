## Source description

The repository's AI Arcade source index identifies the model and labels the files as games. The Astra Bengaluru file is a playable Three.js open-world street game with movement, vehicles, punching, health/stamina, police and respawn. The Astra BLR / After Hours file is a separate playable Three.js open-world action game with driving, vehicle entry/exit, punching, police, health/stamina and WASTED/respawn. The Fable 5.1 Phosphor Siege file is a playable Canvas space-invaders arcade game with waves, shields, shooting and game-over progression. The Ramayana file in the same folder is excluded because it is a cinematic, not a game. Count three source-backed game units under Browser Games.
