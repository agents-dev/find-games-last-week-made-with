## Source description

The public repository is an incremental RPG with story, campaign, quests, areas, equipment, crafting, combat, economy and autoplay systems. It includes a Vite build, a live GitHub Pages deployment, TypeScript application code, core game simulation, tests, linting, type checking and end-to-end checks. The archived build plan records the shipped game rewrite and identifies Opus as the primary executor with Fable-grade implementation work. Count the shipped browser game as one unit.
