## Source description

The README explicitly says MineClaude was built entirely by Claude Opus 4.6 using Claude Code. It is a real Rust/Bevy survival game with infinite voxel terrain, caves, mining, building, crafting, combat, mobs, hunger, farming, storage, saves and a death/respawn loop. The repository contains about 24,000 lines across 41 source files, screenshots, Cargo run instructions and the complete native game source. Classify it under Non-Browser Engines.
