## Source description

The public README describes a turn-based eco-strategy game about human dispersal from East Africa during the last ice age. Source contains deterministic simulation, climate map, bands, passages, campaign timeline, task panel, Field Notes, filesystem/IndexedDB saves, native/browser release gates, tests and Ebitengine rendering. The cited commit adds a playable map-rendering feature and carries a direct Claude Opus 5 co-author trailer. Count the original game as one unit.
