## Source description

The README describes a playable Godot 4 roguelite card game for iOS and Android, documents a Windows build, and states that the prologue runs end to end. game.tscn/game.gd provide the entry flow, battle.gd and combat_state.gd implement combat, and the minigame screens provide additional playable encounters. The repository includes title and battle screenshots; the cited commit includes an exact Co-Authored-By: Claude Opus 5 trailer. This native Godot game belongs in Non-Browser Engines.
