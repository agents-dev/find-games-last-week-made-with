## Source description

The repository is a public, playable browser space-exploration game with Three.js, WebGL2, custom GLSL, seeded systems, scanning, landing, flight, encounters, audio, controls, a live demo and automated browser verification. The README identifies Claude Opus 5 as the original builder. Anshu's X post explicitly says Claude Fable 5.1 overhauled the game, made it more detailed and doubled its speed, and links this repository and the live demo.
