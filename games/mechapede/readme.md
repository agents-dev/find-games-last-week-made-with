## Source description

The README explicitly credits GPT-6 Astra and describes a mechanical Centipede-style arcade game. The repository contains the playable HTML/JavaScript source, rendering, input, collision and enemy-chain systems, audio, browser tests, stress tests and a GitHub Pages deployment. Browser verification opened the public game and showed the start screen, live score, wave, tools remaining, controls, pointer sensitivity and fire instructions; the public build exposes an Engage Drive start control. Classified under Browser Games.
