## Source description

The public repository contains a real Unreal Engine project and a downloadable Windows walkthrough release. README and DOWNLOAD.md give installation and play instructions. The project includes a .uproject, first-person character and camera Blueprints, maps, movement input, guided walking, white-dove flight, interactable doors, tour stops, crowd behavior, save/load and a packaged preview. The repository contains runtime screenshots and release notes. Commit history includes exact Claude Fable 5.1 trailers and Claude Opus 5 trailers; count the Unreal walkthrough once.
